# ⚔️ Mini RO (Idle Ragnarok Online 3D)

A 3D Web-based Idle Ragnarok Online game featuring Class 2-2 & Hi-Class jobs, Job Quests, Real-time Multiplayer PVP, Daily Quests & Daily Login Rewards, and Divine Gods Boss Equipment Sets. Built with **Three.js** and **Node.js WebSocket**.

---

## 🌟 Key Features

- **⚔️ Complete Class & Hi-Class Job System**:
  - **Class 1**: Swordsman, Mage, Archer, Acolyte, Merchant, Thief
  - **Class 2-2**: Crusader, Sage, Bard / Dancer, Monk, Alchemist, Rogue
  - **Hi-Class 2-2**: Paladin, Scholar, Clown / Gypsy, Champion, Creator, Stalker
  - Unique skill trees, class weapons, armor, and Job Master NPCs in Prontera town.

- **⚡ Divine Gods Boss Equipment Sets**:
  - Valkyrie Set, Thor Set, Odin Set, Freya Set with set bonuses.
  - Gods Boss Chest for random Divine Gods set pieces.

- **🎁 Daily & Monthly Login Rewards**:
  - 30-day reward tracking calendar with milestone chests.
  - Day 30 Monthly Grand Jackpot (Gods Chest x5 + Valkyrie Helm + 300,000 Zeny).

- **📜 Daily Quests & Co-op Board**:
  - Monster Hunt, Boss Slayer, PVP Challenger, and Co-op Dungeon Hero quests.

- **🌐 Real-Time Online Multiplayer & PVP Arena**:
  - 1v1, 2v2, and Custom Room PVP matches with target locking & server-authoritative combat via Node.js WebSocket.

---

## 🚀 How to Run

### 1. Start the WebSocket Server
```bash
npm install
npm start
```
*The server starts listening on `ws://localhost:8080`.*

### 2. Launch the Client
Double-click `idleRO_v7.html` in your browser or serve via:
```bash
npx serve .
```
