# นโยบายความสมบูรณ์ 100% ปราศจากข้อผิดพลาด (Zero-Defect & Self-Verification Policy)

## ข้อบังคับสูงสุดสำหรับ AI Agent ทุกตัวในโปรเจกต์นี้ (สำหรับคุณ Digg)

1. **ห้ามส่งงานที่มีบั๊กหรือ Error ให้คุณ Digg ดูโดยเด็ดขาด**
   - งานที่จะรายงานหรือส่งมอบให้คุณ Digg ต้องผ่านการทดสอบจริงแล้ว และผลลัพธ์ต้อง Clean 100% (0 Syntax Errors, 0 Runtime Exceptions, 0 Console Errors)

2. **วงรอบตรวจสอบและแก้ไขอัตโนมัติ (Self-Verification & Auto-Fix Loop)**
   - ทุกครั้งที่เขียนหรือแก้ไขโค้ด (ทั้งฝั่ง Client HTML และ Server JS):
     - รัน Syntax Check ทันที เช่น `node --check`
     - ตรวจสอบ Runtime / Browser Console Errors / Node Server Crash
     - หากพบข้อผิดพลาดหรือบั๊กแม้แต่จุดเดียว **Agent ต้องวิเคราะห์และแก้ไขทันที (Self-Fix) แล้วรันตรวจซ้ำ** จนกว่าจะผ่าน 100%
     - ห้ามส่งงานแบบ "คิดว่าน่าจะใช้ได้" หรือโยนให้ผู้ใช้ไปกดรันแล้วเจอบั๊กเอง

3. **ด่านตรวจความปลอดภัยและคุณภาพ (QA Gate - qa-security-auditor)**
   - ทุกงานต้องผ่านการตรวจจาก QA พร้อมหลักฐานจริง (Command output, Line numbers)
   - หาก QA พบจุดบกพร่อง ให้ Reject ตีกลับไปให้ Agent ที่รับผิดชอบแก้ไขทันที
   - Director จะสรุปผลและรายงานให้คุณ Digg ทราบก็ต่อเมื่อทุกอย่างผ่าน 100% เท่านั้น
